CHAPTER 28 · 统计推断与应用

综合项目实战

前面 27 章各自解决一个子问题。本章把它们接成一条 BPSK 通信链路：估计、检测、自适应与跟踪在同一份数据上协同工作，并用可复现的数值实验核对结论。

读完这一章，你将能够
  • 画出一条端到端链路的信号流，并指出每个环节用到哪一章的工具
  • 把 BPSK 误码率的理论值与种子固定的蒙特卡洛实验对照
  • 说明多径为什么会破坏检测，自适应均衡如何补偿
  • 区分链路中哪些量可以解析预测，哪些必须在线估计

项目要解决什么

单独看，每一项工具都很清楚：匹配滤波器在 AWGN 下最优，周期图能显出谱形，LMS 能在线调系数，卡尔曼滤波能递推状态。但它们很少单独出场。一个真实的接收机要同时做四件事：估计信道与噪声强度，检测每个符号，自适应补偿失真，跟踪缓慢漂移的参数。

本章不引入新定理，而是把全书工具接到一条 BPSK 链路上，并回答两个问题：每个环节用了哪一章的结论？哪些结论可以用数值实验核对？

检测与误码：理论与实验对齐

先看最理想的情形：信道只有加性噪声（h(t)=δ(t)）。匹配滤波器输出在每个符号时刻给出充分统计量，判決就是取符号：

Pb=Q(2Eb/N0)(28.2) BPSK 误码率

这个式子与第 26 章式 (26.5) 是同一个来源：两个等方差高斯分布、均值差为 √(2Eb/N₀) 个标准差。下面用固定种子（seed=42、每点 200000 比特）的蒙特卡洛实验逐点核对。

Eb/N₀ (dB)理论 Q(√(2Eb/N₀))种子仿真（200k 比特）
07.86×10⁻²7.94×10⁻²
41.25×10⁻²1.30×10⁻²
62.39×10⁻³2.35×10⁻³
81.91×10⁻⁴2.60×10⁻⁴（仅 52 个错误）

低信噪比处理论与仿真吻合得很好。到 8 dB，仿真值对应只有 52 个错误事件，其相对标准差约 1/√52≈14%，因此 2.60×10⁻⁴ 与理论 1.91×10⁻⁴ 的偏差处在蒙特卡洛涨落范围内，不是理论失配。要分辨 10⁻⁶ 量级的误码率，需要的比特数远不止几十万——这是仿真评估误码率时最常见的低估。

谱估计与自适应均衡：看见并填平深坑

多径信道不再是 δ(t)。以两径模型为例，h(t)=δ(t)+ρδ(t−Δ)，其频响幅度平方为

|H(f)|2=1+ρ2+2ρcos(2πfΔ)(28.3) 两径频响

当 cos(2πfΔ)=−1 时出现深坑；坑内信噪比很低，判决就会大批出错。这正是频率选择性衰落。接收端第一步是用第 23 章的周期图“看见”这条谱，再用第 25 章的自适应滤波器估计其逆响应，把整体幅度拉平。

反例（不可逆信道）：若多径零点落在单位圆上或圆外（非最小相位），一个因果且稳定的 FIR 逆滤波器不存在。此时只能退而求其次：用 MMSE 准则接受残差干扰，或引入判决反馈均衡（DFE）与延迟，或改用最大似然序列检测。

状态跟踪：把漂移的参数变成状态

信道增益、载波相位、定时偏移都不是常数。第 22 章的做法是把它写成状态空间模型，用卡尔曼滤波递推：

xk=axk−1+wk−1,yk=xk+vk(28.4) 状态与观测

预测步用 a 外推状态与协方差，修正步用导频或判决反馈得到的观测更新估计。过程噪声方差 Q 越大，滤波器越相信新观测、跟踪越快但也越抖；这与第 25 章遗忘因子 λ 的取舍完全同构。

与自适应均衡的分工：均衡器关心“信道形状”，卡尔曼滤波器关心“随时间演化的参数”。两者常级联：先用卡尔曼稳定相位与增益，再让均衡器在已校正的基带上工作。

项目的边界与陷阱

  • 同步：匹配滤波器的最优性建立在精确的定时与载波相位上。定时偏差相当于降低有效信噪比；相位旋转会让判决轴偏移。
  • 噪声功率未知：门限若不随噪声自适应，虚警就会失控（回到第 26 章的 CFAR 问题）。
  • 非最小相位信道：因果且稳定的逆滤波器不存在（图 28.3），只能接受 MMSE 残差或改用 DFE / 序列检测。
  • 模型失配：卡尔曼滤波的过程噪声 Q、观测噪声 R 与实际不符时，估计会低估真实误差甚至发散。
  • 仿真统计：误码率越低，需要的比特数越多（见上表）；用 10 万个比特去估计 10⁻⁶ 的误码率会得到“零错误”的假象。

这些陷阱有同一个结构：每引入一条假设，就新增一个可能被违反的条件。工程可靠性来自对这些条件的检查，而不是来自算法名字。

可复现实验：理论与仿真对照

下面这段程序只用标准库，种子固定，输出与图 28.2、表 28.1 一致。它是全书多个结论的交叉验证：由观测模型到匹配滤波，再到高斯尾概率。

import math, random
def Q(x):
    return 0.5 * math.erfc(x / math.sqrt(2))     # 高斯右尾函数

random.seed(42)
N = 200000                                        # 每点比特数
for db in range(0, 9):
    ebno = 10 ** (db / 10)
    sigma = math.sqrt(1 / (2 * ebno))            # Eb=1 时 N0=1/ebno
    err = 0
    for _ in range(N):
        bit = 1 if random.random() < 0.5 else -1
        r = bit + random.gauss(0, sigma)         # BPSK + AWGN
        if (r > 0) != (bit > 0):                 # 硬判決
            err += 1
    print(f"{db:>2} dB  理论 {Q(math.sqrt(2*ebno)):.2e}  仿真 {err/N:.2e}  错误 {err}")
#  0 dB  理论 7.86e-02  仿真 7.94e-02  错误 15876
#  4 dB  理论 1.25e-02  仿真 1.30e-02  错误 2593
#  6 dB  理论 2.39e-03  仿真 2.35e-03  错误 471
#  8 dB  理论 1.91e-04  仿真 2.60e-04  错误 52

独立练习：把每点比特数从 200000 提高到 2000000，观察 8 dB 处仿真值与理论值的接近程度是否变好；再固定每点比特数不变，把种子换成几个不同的值，估计仿真值的散布。这两个实验分别展示了“样本量”与“随机性”对结论可信度的影响。

全书回顾：从概率到工程

把 28 章压缩成一条链：概率模型（第 1–5 章）给出随机变量的分布与数字特征；随机过程（第 6–11 章）把分布拓到时间，得到相关函数、平稳性与谱；系统与模型（第 12–19 章）讨论信号通过线性系统与窄带、马尔可夫、泊松等结构；统计推断与应用（第 20–28 章）把它变成估计、滤波、检测与工程系统。本章的链路把这四层同时用上了。

自检：本项目里哪些量可以解析预测，哪些必须先估计？

AWGN 下的误码率可以解析（Q(√(2Eb/N₀))）；多径信道形状、噪声功率、载波相位与增益漂移必须先估计或在线适应，它们的准确度直接决定实际性能。

自检：为什么均衡器不能把深坑完全填平？

因为逆滤波在深坑处需要极大增益，会把该频段的噪声一同放大；且非最小相位信道的因果稳定逆根本不存在。工程上是在残差干扰与噪声放大之间取折中。

自检：一次“理论与仿真吻合”的结论需要哪些前提？

需要：仿真确实遵守了模型的假设（理想同步、確知信号、高斯噪声）、样本量足以使估计的误差可接受、且报告了不确实度（误差棒或置信区间）。三者缺一，“吻合”都不够结实。
