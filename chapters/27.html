CHAPTER 27 · 统计推断与应用

现代信号处理前沿

第 23、24 章的谱估计假设信号平稳、采样满足奈奎斯特率。当信号稀疏、欠采样、非平稳，或根本定义在图结构上时，这些前提被逐一放松。

读完这一章，你将能够
  • 说明压缩感知的稀疏假设与恢复条件，并指出它何时失效
  • 对比 STFT 的固定分辨率与小波的多分辨率时频铺砌
  • 解释图傅里叶变换如何把“频率”推广到图拉普拉斯特征值
  • 指出数据驱动谱估计在分布漂移下的风险边界

经典前提何时不够用

第 23、24 章的谱估计依赖几条前提：信号宽平稳、二阶矩有限、采样满足奈奎斯特率；很多推导还默认高斯或线性模型。四类现代场景会逐一打破这些前提：

  • 稀疏：频谱只有少数强分量（窄带干扰、雷达目标）。若已知“稀疏”，能否用比奈奎斯特更少的采样？→ 压缩感知。
  • 非平稳：频率随时间变化（语音、啁啾）。单张功率谱不足以描述，需要时频表示 → STFT 与小波。
  • 图结构：信号定义在传感器网络、社交网络上，不存在天然的时间或空间平移 → 图信号处理。
  • 模型难写但数据充足：用数据驱动模型直接从样本学映射 → 学习型谱估计。

记住一个态度：这些方法不是“更高级所以更好”，而是各自替换掉一条假设，也因此引入新的适用条件。下面逐一看它们换了什么、又在哪里失效。

压缩感知：用稀疏性换采样率

设未知信号 x∈ℂ^N 只有 k 个非零分量，k≪N；我们只能用 m<N 个线性测量 y=Ax（A 为 m×N 测量矩阵）。m<N 时方程欠定、有无穷多解，仅靠 Ax=y 无法确定信号。压缩感知的额外信息就是稀疏先验：在所有满足测量的解中，取非零项最少的那个。

minx∥x∥0s.t.Ax=y→minx∥x∥1s.t.∥Ax−y∥2≤ε(27.1) 零范数与其凸松弛

左边的 ℓ₀ 最小化是 NP 难问题；右边把它换成凸的 ℓ₁ 最小化，可用线性规划求解。恢复保证依赖测量矩阵：若 A 满足阶数 2k 的有限等距性质（RIP），且测量数大致满足 m ≥ C·k·log(N/k)，则 ℓ₁ 能准确恢复。尺度是 k·log(N/k) 而不是 N——省下的采样正是稀疏性提供的。

反例（这不是“无视奈奎斯特”）：若信号并不稀疏（例如宽带噪声），ℓ₁ 会给出有偏的解；若测量矩阵的列高度相干，多个不同的稀疏解会给出相同测量，无法区分。

时频与小波：把分辨率换成另一张铺砌

非平稳信号的频率随时间变化（啁啾、语音共振峰），单张功率谱会把随时间变化的结构平均掉。短时傅里叶变换（STFT）用滑动窗分片处理：

X(t,f)=∫x(τ)w(τ−t)e−j2πfτdτ(27.2) STFT

窗一旦选定，时频分辨率就固定了：长窗频率分得清、但时间模糊；短窗时间定位准、但频率模糊。这是不确定性原理的直接后果，STFT 无法同时兼顾。

Wigner-Ville 分布能给出比 STFT 更高的时频聚集度，但对含多个分量的信号会出现交叉项（虚假的中间频率），通常需要与平滑核折衷使用。

图信号处理：把“频率”推广到网络

传感器网络、点云、脑功能连接上的观测并不具备时间或空间平移，傅里叶变换的 e^{j2πft} 无从定义。图信号处理换了一个出发点：用图拉普拉斯的谱代替频率。设图 G=(V,E)，邻接矩阵 A、度矩阵 D，定义

L=D−A=UΛUT,x^=UTx(27.3) 图傅里叶变换

L 对称半正定，特征值 0=λ₀≤λ₁≤… 就是“图频率”：小特征值对应在相邻节点上平滑变化的模式，大特征值对应在图上剧烈振荡的模式。基于 U 就能定义图上的滤波、采样与谱估计，它们与经典谱分析形式同构，只是“频率轴”变成了图的特征值轴。

典型用例：用图滤波器对节点观测做去噪与插值，或在传感器网络上做分布式估计。注意图本身必须是已知且合理的——图的结构错了，谱也就失去了意义。

数据驱动的谱估计

另一条路线是不再把模型解析写出来，而是用数据学一个从观测到谱（或其低维表示）的映射。这类方法以神经网络为主体，可用于频谱感知、调制识别、协方差估计等任务。

把它放进本章的框架看：它替换的假设是“模型可解析写出”，代价是对训练分布的依赖。在训练分布覆盖良好的场景下，它可以做出经典方法难以做到的事；一旦部署数据与训练数据分布不同，它的性能没有可审计的保证。因此它更像“用样本换先验”，与压缩感知用“稀疏先验”换采样是同一类权衡。

本章不展开网络结构与训练细节。需要强调的是：无论模型多复杂，它仍然隐含地编码了某类先验（平滑、稀疏、低秩…），不存在“无假设”的估计器。

这些方法的边界

  • 压缩感知：需要真稀疏或可压缩，且测量矩阵满足 RIP / 低相干。信号密集或测量高度相干时恢复失败——而失败的解看上去可能仍然“合理”，不会报错。
  • 时频与小波：分辨率受不确定性原理约束，不可能时频同时无限精确；Wigner-Ville 分布的交叉项会造出并不存在的中间频率。
  • 图信号处理：结果完全依赖图的选择；图上不存在天然的平移算子，采样与重建定理比经典情形更脆弱，图的构造错误会直接偷换结论。
  • 数据驱动：分布漂移下性能无可审计保证，且很难给出经典意义上的误差界或置信区间。

共同点：每种方法都用一条更强的假设换来了经典方法做不到的能力。不要把“新方法”误当成“无假设”，也不要在没有核对分布与稀疏性前提时就相信结果。

用 25 行代码实验稀疏恢复

下面的程序构造一个 N=6、k=2 的稀疏信号，只用 m=4<N 个随机线性测量。由于规模很小，我们直接穷举所有 2 稀疏支撑（即 ℓ₀ 最小化），对每个支撑解最小二乘，取残差最小者。结果精确重现了真实信号的两个非零项。

import random, itertools
random.seed(3)
N, m, k = 6, 4, 2
A = [[random.gauss(0, 1) for _ in range(N)] for _ in range(m)]
xt = [0.0]*N; xt[1] = 2.0; xt[4] = -1.5     # 真信号（2 稀疏）
y = [sum(A[i][j]*xt[j] for j in range(N)) for i in range(m)]

def lsq(S):                                  # A_S 上的最小二乘（法方程）
    G = [[sum(A[i][u]*A[i][v] for i in range(m)) for v in S] for u in S]
    b = [sum(A[i][u]*y[i] for i in range(m)) for u in S]
    for c in range(len(S)):                  # 高斯消元
        p = max(range(c, len(S)), key=lambda r: abs(G[r][c]))
        G[c], G[p] = G[p], G[c]; b[c], b[p] = b[p], b[c]
        for r in range(c+1, len(S)):
            f = G[r][c]/G[c][c]
            for cc in range(c, len(S)): G[r][cc] -= f*G[c][cc]
            b[r] -= f*b[c]
    a = [0.0]*len(S)
    for r in range(len(S)-1, -1, -1):
        a[r] = (b[r]-sum(G[r][cc]*a[cc] for cc in range(r+1, len(S))))/G[r][r]
    return a

best = None
for S in itertools.combinations(range(N), k):
    a = lsq(S); res = sum((y[i]-sum(a[t]*A[i][S[t]] for t in range(k)))**2 for i in range(m))
    if best is None or res < best[0]: best = (res, S, a)
_, S, a = best
xr = [0.0]*N
for t, j in enumerate(S): xr[j] = a[t]
print(S, [round(v, 3) for v in xr])          # (1, 4) [0.0, 2.0, 0.0, 0.0, -1.5, 0.0]
assert all(abs(xr[j]-xt[j]) < 1e-6 for j in range(N))

独立练习：把真实信号改为 5 个非零项（k=5），保持 m=4，观察恢复是否还唯一；再逐步增大 m 直到能恢复。这个实验直观展示了“测量数要随稀疏度增长”的尺度关系 m∝k·log(N/k)。

一条共同的主线：用先验换能力

把本章与第 23、24 章放在一起，可以看到一条清晰的主线：经典谱估计建立在平稳、奈奎斯特采样、二阶矩这几条假设上；每一个现代工具都放大了其中一条假设的适用范围，又注入了一条新的先验——压缩感知注入稀疏，时频与小波注入“频率缓慢变化”的局部结构，图信号处理注入图拓扑，学习型方法注入训练分布。先验越强，能做到的事越多，但一旦先验不成立，失效也越严重。

自检：压缩感知真的“绕过了奈奎斯特率”吗？

严格说不是。信号的可自由度数（信息率）仍然受限于稀疏度 k；压缩感知把采样数从 N 降到约 k·log(N/k)，靠的是信号的稀疏结构，而不是让欠采样本身变得无损。对非稀疏信号，它不提供任何保证。

自检：为什么图的“频率”不能直接用拉普拉斯特征值的大小排序理解？

L 的特征向量是图上的正交模式，特征值衡量模式在边上的变化快慢。但“快”与“慢”是对这张图而言的；换一张连接方式，同一信号的谱就变了。没有图，就没有图频率。

自检：一个“深度学习谱估计在实验中胜出”的结论需要什么额外信息才能相信？

至少需要：训练与测试分布是否相同、信噪比与信道条件是否匹配、对比的经典方法是否调好、以及是否报出了分布漂移下的性能。缺少这些，实验胜出不能推广到部署环境。
