CHAPTER 25 · 统计推断与应用

自适应滤波及应用

第 21、22 章的最优滤波都需要事先知道统计特性或系统模型。如果这些量未知、甚至随时间漂移，滤波器就只能一边工作一边估计——这就是自适应滤波。

读完这一章，你将能够
  • 写出 LMS 的随机梯度更新，并说明步长必须满足的收敛条件
  • 解释 RLS 为什么收敛更快，又付出了怎样的计算代价
  • 判断自适应噪声抵消成立所需的相关性前提，并识别步长选错导致的发散

当统计特性未知、甚至随时间变化时

第 21 章的维纳滤波解来自维纳-霍夫方程 R w = p：只要输入自相关矩阵 R 和互相关向量 p 已知，它就是均方误差意义下的最优线性解。第 22 章的卡尔曼滤波同样要求状态方程与噪声协方差已知。但它们都默认这些统计量事先可测且不随时间改变。

真实场景很少满足这个前提：免持通话的回声路径随房间和人员走动而变，移动通信的多径信道在毫秒级抖动，车间背景噪声的功率随设备启停起落。此时固定滤波器从设计那一刻起就已经失配。

本章的核心问题：如果不显式估计 R 与 p，而是让滤波器每来一个样本就朝减小瞬时误差的方向挪动一小步，它能否自动逼近、并持续跟踪那个未知的最优解？

本章只讨论线性自适应：滤波器的结构（FIR 抽头或 IIR 递归）固定，算法在线调整的只是系数向量。非线性自适应、基于神经网络的滤波不在讨论范围内。

一个最小模型：自适应噪声抵消

先固定一个完全指定的模型。设主输入为期望信号与噪声之和，另有一路参考输入：

d[n]=s[n]+v0[n],e[n]=d[n]−wTx[n](25.1) 噪声抵消的输入输出

其中 x[n]=[x[n],x[n−1],…,x[n−N+1]]ᵀ 是由参考信号构成的 N 维向量，w 是待定系数。关键假设是：参考 x[n] 与噪声 v₀[n] 相关，却与目标信号 s[n] 不相关。

在平稳、联合二阶矩存在的假设下，均方误差是 w 的二次函数：

J(w)=E[e2[n]]=σd2−2wTp+wTRw(25.2) 二次代价面

这里 R=E[x xᵀ] 对称半正定，p=E[d x]。对 w 求梯度并令其为零，得到的正是第 21 章的维纳解 w*=R⁻¹p，前提是 R 正定（可逆）。自适应滤波并不推翻这个解，它只是用数据在线逼近这个解。

LMS：用瞬时值代替统计量

最速下降法沿负梯度方向迭代：w[n+1]=w[n]−(μ/2)∇J(w[n])，代入式 (25.2) 的梯度 ∇J=2(Rw−p) 得 w[n+1]=w[n]+μ(p−Rw[n])。问题在于 p 和 R 仍然未知。

LMS（最小均方）的关键一步是：用瞬时估计 e[n]x[n] 代替期望 p−Rw[n]。在平稳假设下 E[e[n]x[n]]=p−Rw[n]，所以这个替换是无偏的；代价是每次只用了一个样本，迭代方向上叠加了噪声。于是得到只需当前样本的更新：

w[n+1]=w[n]+μe[n]x[n](25.3) LMS 更新

运算量只有 O(N) —— 一次内积加一次向量更新，非常适合实时实现。但它对步长 μ 敏感。把式 (25.3) 在均值意义下分解到 R 的特征方向上，可得收敛条件：

0<μ<2λmax(25.4) 收敛条件

其中 λmax 是 R 的最大特征值。工程上常用一个更保守、无需做特征分解的上界 0<μ<2/(N·P_in)，P_in=E[x²] 是输入平均功率。注意：这个条件里出现的是输入功率，不是采样点数——当输入功率变大，原本安全的步长就可能越界。

稳态失调是 LMS 绕不开的代价：由于瞬时梯度含噪，系数在最优值附近持续抖动，使收敛后的均方误差高于维纳解。前馈去耦近似给出额外均方误差比 M ≈ (μ/2)·tr(R)。要让失调变小就得减小 μ，但收敛也变慢——图中两条曲线的横向位置就是这个矛盾。

RLS：用逆相关矩阵换收敛速度

LMS 的收敛快慢取决于 R 的特征值散布（条件数）：输入接近白噪声时很快，输入高度有色时很慢。RLS（递归最小二乘）换了一个目标：最小化从开始到现在的指数加权残差平方和，而不是瞬时误差的期望。

Jn(w)=∑k=1nλn−ke2[k](25.5) 遗忘因子 λ∈(0,1]

令 Φ[n]=Σ λ^{n−k}x[k]x[k]ᵀ（加上小的正则项 δI 保证可逆），z[n]=Σ λ^{n−k}d[k]x[k]，则最优条件仍是线性方程组 Φ[n]w=z[n]。RLS 的高明处在于递推更新 Φ⁻¹，而不每次重新求逆：

k[n]=P[n−1]x[n]λ+xT[n]P[n−1]x[n](25.6) 增益向量，P=Φ⁻¹
w[n]=w[n−1]+k[n](d[n]−xT[n]w[n−1]),P[n]=P[n−1]−k[n]xT[n]P[n−1]λ(25.7) 系数与逆矩阵更新

代价是每步 O(N²) 的矩阵运算。对 N=128 阶的滤波器，RLS 每步约需上万次乘加，而 LMS 只要百次级。但回报也明显：当 λ=1 且输入平稳时，RLS 在约 2N 步内逼近维纳解，收敛速度基本不受特征值散布影响。

三类典型应用与它们各自的前提

1. 自适应噪声抵消

回到图 25.1 的结构。当滤波器收敛时 ŷ[n]≈v₀[n]，输出 e[n] 只剩目标信号。这类结构常用于从含噪声的多路传感器信号中提取相关分量。但注意它的成立前提：

  • 参考通道必须与噪声相关，否则滤波器无从预测噪声；
  • 参考通道必须与目标信号不相关，否则相减会连带削弱有用信号；
  • 噪声源到两个传感器的通道差异要能被 N 阶 FIR 近似，否则抵消不充分。

2. 自适应信道均衡

信号经多径信道后产生码间干扰。均衡器以接收信号为输入、以发送符号为期望响应，逆滤波补偿信道。常见做法分两段：先用一段接收端已知的训练序列驱动自适应（此时“期望响应”可靠），再切换到决策导向模式，用判决输出作为伪期望继续跟踪信道缓变。

3. 声学回声消除

免持设备的扬声器声音被麦克风再次拾取形成回声。回声消除器用自适应滤波器估计扬声器到麦克风的声学冲激响应，再从麦克风信号中减去估计的回声。声学路径的冲激响应可能长达数百毫秒，对应数千阶 FIR；此时 O(N²) 的 RLS 不现实，工程上几乎都使用 NLMS（见下节）。

对比第 21 章的维纳滤波与第 22 章的卡尔曼滤波：维纳滤波需要离线已知的 R 与 p，卡尔曼滤波需要模型与协方差；自适应滤波不要求这些先验，代价是收敛需要时间、稳态存在失调，且跟踪速度与稳态精度相互制约。

步长选错会发散，而不是变慢

式 (25.4) 不是“建议值”，而是稳定性边界。把 LMS 的均值迭代写作 E[w[n+1]]=(I−μR)E[w[n]]+μp，误差 v[n]=E[w[n]]−w* 满足 v[n+1]=(I−μR)v[n]。只有当 I−μR 的所有特征值落在 (−1,1) 内，误差才收敛；否则会指数放大。

反例（输入功率跳变导致发散）：设某时刻输入为白噪声，R=0.04·I（单特征值 0.04），选 μ=30 似乎仍在 2/λmax=50 以内。若随后输入功率上升为 R=0.4·I，则 2/λmax=5，同一个 μ=30 立即越界，I−μR 的特征值变为 1−30×0.4=−11，误差按约 11 倍逐代放大，系数迅速爆炸。这就是“实验室安静、现场嘈杂”时 LMS 失稳的机理。

NLMS 修正：把步长除以输入瞬时功率，使实际步长随功率自动缩放：

w[n+1]=w[n]+μ∥x[n]∥2+εe[n]x[n](25.8) 归一化 LMS，ε>0 防零除

当 0<μ<2 时，NLMS 对输入功率的变化保持稳定。因此凡是输入功率可能大幅波动的场合（语音、回声消除），应优先使用 NLMS 而不是固定步长的 LMS。

RLS 的边界：P=Φ⁻¹ 在 Φ 病态时会放大数值误差，需靠正则项 δI 或平方根实现稳定；遗忘因子 λ<1 能跟踪时变系统，但等效记忆变短、估计方差上升。换句话说，“能跟踪”和“估计得准”也是一对取舍，只是它藏在 λ 里。

用一段确定性代码验证 LMS 确实收敛

下面的例子做系统辨识：让 LMS 去拟合一个未知的 3 抽头 FIR 系统 h=[0.9,−0.4,0.2]。随机数用固定种子，只用标准库，结果可复现。步长 μ=0.05 满足式 (25.4) 的保守上界 2/(N·P_in)=2/(3×1/3)=2。

import random
random.seed(7)
h = [0.9, -0.4, 0.2]          # 未知 FIR 系统
w = [0.0, 0.0, 0.0]          # 待学习系数
mu = 0.05                     # 步长（满足 0 < mu < 2/(N*P_in)）
xs = [random.uniform(-1, 1) for _ in range(4000)]   # x ~ U(-1,1)

for n in range(2, 4000):
    x = [xs[n], xs[n-1], xs[n-2]]
    y = sum(w[k]*x[k] for k in range(3))            # 滤波输出
    d = sum(h[k]*x[k] for k in range(3))            # 期望响应
    e = d - y                                        # 误差
    for k in range(3):
        w[k] += mu * e * x[k]                        # LMS 更新 (25.3)

print([round(v, 3) for v in w])   # → [0.9, -0.4, 0.2]
assert abs(w[0]-0.9) < 0.05 and abs(w[1]+0.4) < 0.05 and abs(w[2]-0.2) < 0.05

独立练习：把 mu 改为 3.0（超过上界 2），观察 w 是否迅速飞到极大的数；再把它改回 0.05，但把 xs 的幅度乘 10（模拟输入功率变大），此时原来的 mu 是否已经越界？最后用式 (25.8) 的 NLMS 重做一遍，验证它对输入幅度缩放不敏感。

把“自适应”接回整本书的脉络

从第 20 章的估计理论到第 21–22 章的维纳/卡尔曼滤波，再到本章，主线是同一个：从已知统计量出发求最优解，再把它放松成只需观测就能在线逼近的方法。LMS 用瞬时梯度替换期望，RLS 用逆相关矩阵替换特征值分解，两者都在回答一个问题——当先验知识不足时，哪些先验是必须的，哪些可以用数据换？

自检：LMS 的收敛条件为什么与 λmax 而不是 N 有关？

均值迭代是 v[n+1]=(I−μR)v[n]。把 R 对角化后，每个特征方向上的误差按 1−μλᵢ 缩放，稳定性要求所有 |1−μλᵢ|<1，最紧的约束来自最大的 λᵢ。工程上界 2/(N·P_in) 只是用 λmax≤tr(R)=N·P_in 做的保守替换。

自检：参考通道里混入了目标信号会怎样？

噪声抵消要求参考与 s[n] 不相关。若参考含 s[n] 分量，滤波器会学着去预测这一部分，相减时把真正的信号也一并减掉，输出产生失真。这是实际 ANC 设计中最常见的失败原因。

自检：RLS 收敛快，为何不总是用它？

因为每步 O(N²)，且 P 的递推对数值精度敏感。长冲激响应（如回声消除）下计算量不可接受，因此工程上常用 NLMS 或块处理、子带方法在两者之间取折中。
