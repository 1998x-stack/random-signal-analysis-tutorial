CHAPTER 26 · 统计推断与应用

信号检测与假设检验

前面的章节都在估计“信号是多少”。检测问的是更根本的问题：给定一串观测，信号究竟“有”还是“没有”？

读完这一章，你将能够
  • 写出二元假设、虚警概率与检测概率，并区分漏检与虚警
  • 说明 Neyman-Pearson 引理给出的似然比检验为何在固定虚警下最优
  • 对确知信号推导匹配滤波器输出，并算出 Pfa 与 Pd 的闭式表达
  • 读懂 ROC 曲线与 AUC，并指出固定阈值在非平稳噪声下的失效

“有信号”是一个可以被证伪的判断吗？

前面各章处理的是估计与滤波：默认信号存在，去还原它的参数、频谱或波形。检测面对的是更前置的一步。雷达收到一段回波、通信接收机收到一个符号周期内的采样，观测本身并不能直接告诉你“目标在不在”。

关键转变是：把“有无”表述成两个互斥的概率模型，再设计一个判决规则，使得错误出现的频率可以被计算、被控制。本章只处理二元检测；多元检测与序贯检测是它的自然推广。

检测与估计的区别：估计的输出是连续参数（幅度、时延、频率），检测的输出是离散决策。工程上二者常级联——先判决是否存在，再对存在的情形估计参数。

二元假设与两类错误

把观测记为随机向量 Y，两个互斥假设分别给出它的分布：

H0:Y∼p0(y)H1:Y∼p1(y)(26.1) 二元假设

判决规则就是把观测空间分成两块：落入 R₁ 就判 H₁，落入 R₀ 就判 H₀。由此产生两种错误：

Pfa=∫R1p0(y)dy,Pd=∫R1p1(y)dy=1−Pm(26.2) 虚警与检测

其中 Pfa 是“无信号却判有”的虚警概率，Pm 是“有信号却判无”的漏检概率，检测概率 Pd=1−Pm。一个具体的一维示例能说清三者的几何关系。

图 26.1 的取舍是检测问题的中心矛盾：降低虚警必然降低检测概率。除非改变两个分布在统计上的可分性（例如提高信噪比、增加观测时长），否则无法同时改善两者。

Neyman-Pearson：固定虚警，最大化检测

两个错误都不可消除，但它们的代价往往不对称：漏检一架飞机可能意味着灾难，而多一次虚警只是多一次确认。Neyman-Pearson（NP）准则因此把虚警拉成硬约束：给定可容忍的虚警上限 α，在所有满足 Pfa≤α 的检验中，选检测概率 Pd 最大的那个。

NP 引理给出的答案是似然比检验（LRT）。把两假设下的密度之比定义为似然比：

Λ(y)=p1(y)p0(y)≷H0H1η(26.3) 似然比检验

门限 η 由虚警约束确定：Pfa=P(Λ(y)>η | H₀)=α。为什么 LRT 一定最优？直观地说，在门限右侧每一点上，H₁ 的可能性至少是 H₀ 的 η 倍；把判决域往“H₁ 相对可能性更高”的方向扩，必然以更大的虚警为代价。当似然比关于某个统计量 T(y) 单调时（常见的指数族都满足），LRT 就简化为“T(y) 超过某个门限”。

与 MAP 检验的区别：若已知两假设的先验概率且代价可量化，最小错误率准则（或 Bayes 风险最小）会用先验与代价共同定门限；NP 准则不需要先验，只用虚警上限 α 定门限，更适用于先验不可靠的工程场景。

AWGN 中最优检测：匹配滤波器

设观测为 r(t)=s(t)+n(t)，0≤t≤T，其中 s(t) 是确知信号、能量 E=∫s²(t)dt，n(t) 是双边谱密度为 N₀/2 的白高斯噪声。当似然比化简后，最优统计量是相关积分，等价于让信号通过一个冲激响应为时间反转的滤波器：

h(t)=s(T−t),y(T)=∫0Tr(t)s(t)dt(26.4) 匹配滤波器

在 t=T 采样后，门限判决只面对两个一维高斯分布：H₀ 下 y∼N(0,σ²)，H₁ 下 y∼N(E,σ²)，其中 σ²=N₀E/2。定义归一化距离 d′=E/σ=√(2E/N₀)，则性能有闭式表达：

Pfa=Q(γ/σ),Pd=Q(Q−1(Pfa)−2E/N0)(26.5) 检测性能

其中 Q(x)=(1/√(2π))∫_x^∞ e^(−u²/2)du 是高斯右尾函数。式 (26.5) 说明：可检测性完全由单个量 √(2E/N₀) 决定。取 E/N₀=4.5 则 √(2×4.5)=3；若要求 Pfa=0.01，则 γ/σ=Q⁻¹(0.01)≈2.326，于是 Pd=Q(2.326−3)≈0.750。这三个数字将在可复现验证中直接算出。

ROC 曲线与 AUC

固定信噪比、连续改变门限 γ，会得到一整条 (Pfa, Pd) 轨迹，这就是接收机工作特性（ROC）曲线。它把检测器的全部工作点一次画完：门限向左移，工作点沿曲线向右上移动（高虚警、高检测）；向右移则向左下移动。

用一个数字概括整条曲线，就是曲线下面积 AUC。在等方差高斯模型下它与 d′ 有闭式关系 AUC=Φ(d′/√2)=Q(−d′/√2)：d′=3.0 对应 AUC≈0.983。AUC=0.5 是随机猜测，AUC=1 是完美检测；它不依赖具体门限，适合比较不同检测器的可分性上限。

AUC 只说明“排序能力”，不说明某个门限下的实际性能。两个 AUC 相同的检测器，在 Pfa=0.01 处可能一个更好、另一个更差。工程上应同时看目标工作点附近的 ROC 局部形状。

何时这些结论会失效

反例一：固定门限遇上变噪声功率

式 (26.5) 把 Pfa=Q(γ/σ) 写成 γ 和噪声标准差 σ 的二元函数。如果按某个标称σ定好门限，而实际噪声变大，虚警会失控。具体地，仍取 γ/σ=2.326（对应 Pfa=0.01）；若噪声功率翻四倍、σ 变成 2 倍，则新的虚警为 Q(2.326/2)=Q(1.163)≈0.122——从 1% 蹦到 12%。

解决办法不是重新发明检测器，而是让门限随噪声自适应：用邻近参考单元估计当前噪声功率，再按目标 Pfa 设定门限（恒虚警率，CFAR）。这正是“固定门限在非平稳噪声下失效”的标准对策。

边界二：相位未知时匹配滤波器不再可用

式 (26.4) 要求 s(t) 完全已知，包括载波相位。若相位 φ 在 [0,2π) 上未知，对 φ 取平均后，最优统计量变成包络（非相干检测）：H₀ 下包络服从瑞利分布，H₁ 下服从莱斯分布。与相干检测相比，非相干检测在高信噪比下大约损失 1 dB 量级，越接近检测门限损失越大。具体损失随误判要求而变，此处只作量级说明（教学简化）。

边界三：高斯与白噪声假设

式 (26.5) 的高斯尾部形式依赖于噪声服从高斯分布且各样本独立。若噪声重尾（脉冲噪声）、或相邻采样相关（有色噪声），同一门限下的真实 Pfa 会与公式严重偏离，尤其是小概率尾部。此时应改用噪声的实际分布，或先做预白化再检测。

小结：本章的闭式公式建立在“确知信号 + 平稳高斯白噪声”之上。一旦信号参数未知、噪声非平稳或非高斯，检测器结构或门限就必须相应修改，而 NP 引理本身仍然成立——变的只是似然比的具体形式。

用 15 行代码把三个数算出来

下面的程序只用标准库 math，不用仿真采样，直接对式 (26.5) 做数值计算；Qinv 用二分法求反函数。结果确定可复现。

import math
def Q(x):
    return 0.5 * math.erfc(x / math.sqrt(2))
def Qinv(p):
    lo, hi = -10.0, 10.0
    for _ in range(200):          # 二分法求 Q 的反函数
        mid = (lo + hi) / 2
        if Q(mid) > p: lo = mid
        else: hi = mid
    return (lo + hi) / 2

E_over_N0 = 4.5
d_prime = math.sqrt(2 * E_over_N0)     # d' = sqrt(2E/N0) = 3.0
threshold = Qinv(0.01)                # 门限/σ，由 Pfa=0.01 定出
Pfa = Q(threshold)                    # 0.0100
Pd  = Q(threshold - d_prime)          # ≈ 0.7497
AUC = Q(-d_prime / math.sqrt(2))      # ≈ 0.9831
print(d_prime, Pfa, Pd, AUC)
assert abs(Pfa - 0.01) < 1e-3 and abs(Pd - 0.7497) < 1e-3

独立练习：保持 Pfa=0.01，把 E/N₀ 从 4.5 提到 18（则 d′=6），预测 Pd 会怎样变化，再用代码核对。进一步：若噪声功率翻四倍而门限不变，用 Q(threshold/2) 算出的 Pfa 是否与上节估算一致？

把检测接回估计与滤波的主线

第 20–22 章解决“信号有多大”，第 25 章解决“统计未知时如何自适应”，本章解决“信号是否存在”。三者的共同语言是条件分布：估计与检测都从 p(y|θ) 或 p(y|Hᵢ) 出发，区别只在输出是连续参数还是离散决策。匹配滤波器同时出现在检测与估计中——它最大化输出信噪比，因此既是最优检测器，也是时延估计的前端。

自检：为什么不直接选一个使 Pfa+Pm 最小的门限？

那需要两个错误的先验概率与代价可比。NP 准则回避了这个难题：它只要求 Pfa 不超过给定上限，不需要先验，也不需要对“漏检 vs 虚警”的代价定量。

自检：d′=3 与 Pfa=0.01 为何能直接给出 Pd？

因为两个假设下的输出都是等方差高斯分布，且均值差固定为 d′σ。于是检测性能只依赖 d′ 与门限，与信号的波形无关。

自检：AUC 相同是否意味着两个检测器一样好？

不一定。AUC 是全局平均指标；工程关心的往往是某个低虚警工作点。应结合目标 Pfa 处的 ROC 局部斜率来比较。
